# 📅 NoteSbot — Telegram-бот ежедневник с напоминаниями

Простой и удобный Telegram-бот на Python, который помогает не забывать о предстоящих делах и событиях. Бот сохраняет ваши записи и присылает уведомления ровно в назначенное время.

## ✨ Возможности

- 📝 **Добавление дел** — с текстом и точным временем напоминания.
- ⏰ **Гибкий ввод времени** — можно указать точную дату (`25.12.2026 18:30`) или относительное время (`+30m`, `+2h`, `+1d`).
- 🔔 **Автоматические напоминания** — бот пришлёт уведомление, как только наступит нужный момент.
- 📋 **Список дел** — просмотр всех активных записей.
- ✅ **Отметка о выполнении** — удаление или завершение дел одной командой.
- 💾 **Локальная база данных** — все записи хранятся в SQLite (файл `reminders.db`), данные не теряются при перезапуске.

## 🛠 Технологии

- **Python 3.10+**
- **[pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI)** (`telebot`) — работа с Telegram API
- **SQLite** — хранение данных
- **threading** — фоновый поток для проверки времени напоминаний
- **datetime** — работа с датами и временем
