# 📅 NoteSbot — Telegram-ежедневник и заметки

Простой и удобный Telegram-бот на Python, который помогает не забывать о делах и сохранять важные заметки. Бот работает локально, хранит все данные в базе SQLite и не требует сторонних сервисов.

## ✨ Возможности

- 📝 **Напоминания** — добавляй дела и указывай точное время (или относительное, например `+30m`).
- 🔔 **Автоматические уведомления** — бот пришлёт сообщение, как только наступит нужное время.
- ✅ **Управление делами** — отмечай выполненными или удаляй одним нажатием на Inline-кнопку.
- 📒 **Заметки** — сохраняй любые тексты (списки продуктов, идеи, пароли) через команду `/note`.
- 🗑 **Удаление заметок** — тоже по кнопке, без ввода лишних команд.
- 🆔 **Последовательные ID** — дела и заметки нумеруются по порядку (1, 2, 3...), без «дырок» от удалённых записей.
- 💾 **Локальная база** — все данные хранятся в файле `reminders.db`, не теряются при перезапуске.

## 🛠 Технологии

- **Python 3.10+**
- **[pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI)** (`telebot`)
- **SQLite** — лёгкая встроенная база данных
- **threading** — фоновый поток для проверки времени напоминаний
- **datetime** — работа с датами и временем
